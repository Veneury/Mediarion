# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be civil, assume the other person is arguing in good faith, and keep the argument about
the code. Disagreement about a design decision is the point of a review and is welcome. Being
unpleasant to the person on the other side of it is not.

Report anything that needs reporting through GitHub's private vulnerability reporting on
<https://github.com/Veneury/Mapperion>, which reaches the maintainers and nobody else. It is not
what that channel was built for, but it is private and it works.
